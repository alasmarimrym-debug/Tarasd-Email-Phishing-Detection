# Tarasd (تَرصُد) 🛡️
### AI-Powered Email Phishing Detection & Cybersecurity Awareness

## 📌 Project Overview
**Tarasd** is an intelligent system designed to protect Small and Medium Enterprises (SMEs) from phishing threats. It features a Windows-compatible desktop application that utilizes **Machine Learning (ML)** and **Natural Language Processing (NLP)** to analyze Gmail messages with high accuracy.

## 🚀 Key Components
- **Desktop Application:** Real-time phishing detection for Gmail with instant security alerts.
- **Smart AI Assistant:** A conversational desktop tool providing interactive educational tips to enhance user cybersecurity awareness.
- **Product Landing Page:** A dedicated website for software distribution and communicating the project’s vision.

## 🧠 Future Vision
- Implementing **UEBA (User and Entity Behavior Analytics)** for anomaly detection.
- Supporting multiple email providers beyond Gmail.
